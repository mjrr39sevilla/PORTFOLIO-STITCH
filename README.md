# 🚀 Tecnologías Utilizadas

Este proyecto ha sido construido utilizando un stack moderno para garantizar escalabilidad y facilidad de mantenimiento:

* React.js: Biblioteca principal para la construcción de la interfaz de usuario basada en componentes.

* Tailwind CSS: Framework de CSS utility-first para un diseño rápido, personalizado y responsivo.

* Lucide React / Icons: Set de iconos vectoriales para una navegación intuitiva y visualmente atractiva.

* Framer Motion: (Opcional/Recomendado) Para animaciones suaves y transiciones de estado.

* Diseño Mobile-First: Optimizado específicamente para dispositivos móviles y adaptable a pantallas de escritorio.

# 📋 Estructura del Proyecto

El portfolio se organiza en secciones modulares para facilitar la lectura y el acceso a la información:

* Hero Section: Presentación personal con fotografía profesional, título de perfil y llamadas a la acción (CTAs).

* Sobre mí: Descripción detallada de la experiencia profesional, enfoque en resolución de problemas y calidad de código.

* Formación: Línea de tiempo que detalla la educación académica y bootcamps especializados.

* Stack Tecnológico: Grid visual de tecnologías (Frontend, Backend, Bases de Datos, Cloud).

* Proyectos Destacados: Tarjetas detalladas con imágenes reales, etiquetas de tecnologías y enlaces a detalles.

* Contacto: Formulario funcional y minimalista para captación de leads y colaboraciones.

* Navegación: Menú fijo superior y barra de navegación inferior optimizada para móviles.

# 🛠️ Instalación y Configuración

Para ejecutar este proyecto localmente, sigue estos pasos:

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
